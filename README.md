# tabbybot

維洛傳說（Tabby，官方網站 [game.tabby.meme](https://game.tabby.meme/)，開發者公開支持玩家寫自動化腳本）的非官方 macOS 單帳號工具。

第一版只做兩件事：

1. 在指定地圖上自動巡邏、追擊並攻擊怪物
2. 依本機規則監控商城上架並顯示符合條件的商品（**不會自動購買**）

連線只會打到官方伺服器 `game.tabby.meme`。沒有自動更新、沒有遙測、不會把私鑰或會話送到其他主機。協定是參考公開客戶端與開源專案 [tabbyShop](https://github.com/TokenScience01/tabbyShop) 重新實作，不是執行它的程式。

## 請用空的專用錢包

私鑰只在本機用來對官方登入挑戰做 EIP-191 簽名。請務必使用**裡面幾乎沒有資產的遊戲專用錢包**，不要匯入常用錢包或有大量代幣的地址。主密碼只留在記憶體，保險庫以 scrypt + AES-GCM 加密後寫到 `~/.tabbybot/wallet.vault`。忘記主密碼只能重新匯入私鑰。使用自動化有被遊戲處分的風險，請自行判斷。

這個倉庫的測試都是離線的，**沒有拿真實私鑰連過正式伺服器**。線上行為仍需你自己驗證。

## 在 Mac 上安裝

需要 Python 3.9 或更新版本（Mac 系統內建的 3.9 即可）。

```bash
cd tabbybot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
```

用你的編輯器改 `config.yaml`：刷怪地圖（預設 `2` 北部雪地）、等級範圍、商城品質與價格區間。不要把私鑰寫進設定檔。

本機離線測試：

```bash
python -m unittest discover -s tests -v
```

## 給家人用的圖形介面

在 Finder 裡打開 `tabbybot` 資料夾，連按兩下「啟動 Tabby.command」。瀏覽器會開啟本機頁面（http://127.0.0.1:8765/），只有這台電腦可以看。

1. 第一次：貼上專用錢包的私鑰或助記詞，設定主密碼，按「保存並開始使用」。
2. 保險庫已經存在時，第一次開啟會請你輸入主密碼；請保持「記住此電腦」勾選，之後再開就會自動解鎖。主密碼只會進這台 Mac 的鑰匙圈，保險庫檔案本身仍是加密的。可在右上角取消「開啟時自動解鎖」。
3. 在「遊戲控制台」選好地圖，按「開始打怪」或「停止打怪」。
4. 「任務」面板可看今日任務。按「開始每日任務」會自動接取打怪任務、走到任務地圖、只打任務怪，完成後接下一個，直到今日額度用完。
5. 需要交付裝備或消耗道具的任務不會自動交出。程式會暫停並列出將消耗的物品與數量，只有按「確認交付」後才會提交。「跳過」只對尚未接取的任務有效。開啟「需要交道具或裝備的任務自動換掉」時，會略過尚未接取的交付任務並改接打怪任務；遊戲本身沒有更換或放棄任務的接口，已接取的交付任務仍需你確認。廢棄遺跡、秘寶之地不會使用入場券。
6. 切到「商城與監控」可設定商品名稱與最高價，開始或停止監控。這一版不會自動購買。
7. 「自動使用生命藥水」這一版還沒有，按鈕是關掉的。裝備對比也還沒做。

命令列仍然可用：`python -m tabbybot gui`。

## 使用方式

```bash
# 輸入私鑰或助記詞，選擇是否用主密碼加密保存（建議加 --save）
python -m tabbybot login --save

# 查看目前設定（不會顯示機密）
python -m tabbybot status

# 自動巡邏打怪
python -m tabbybot hunt

# 監控商城；只顯示符合條件的上架，不會下單
python -m tabbybot market
```

私鑰來源依序為：

1. 環境變數 `TABBY_PRIVATE_KEY`（較不建議，仍請勿寫進腳本或日誌）
2. 已保存的保險庫，啟動時輸入主密碼（也可用 `TABBY_VAULT_PASSWORD`）
3. 執行時互動輸入（輸入過程不會顯示）

按 Ctrl-C 可乾淨結束。免費 Apple 生態沒關係，這個工具是本機 Python，不必簽名安裝到手機。

## 刷怪說明

- 只操作一個帳號、一張地圖。若角色還沒建立，請先到官方客戶端建立，本工具不會代你創角。
- 若人在相鄰地圖（例如維洛鎮 ↔ 北部雪地），會嘗試送出切圖請求。廢棄遺跡、秘寶之地需要特殊道具，第一版不會自動進入。
- 沒有目標時依導航資料做整圖巡邏；發現怪物會改為尋路追擊，並使用伺服器下發的攻擊票據。
- 陣亡後會請求復活；若復活點不在目標地圖，會再嘗試一次相鄰切圖。
- 已有導航資料的地圖：1 維洛鎮、2 北部雪地、7 秘寶之地、8 黑石洞窟、9 失落綠洲、10 冰封洞穴。其他地圖會改走直線靠近，可能被地形擋住。

## 商城監控

依 `config.yaml` 的品質、價格區間（最低價包含、最高價不含）與名稱關鍵字過濾 `GET /api/shop` 的結果。符合的新商品會印在終端機。第一版沒有下單、報價或鏈上轉帳功能。

## 更新紀錄

### 2026-11-12
- 怪堆永久記憶：探索時看到的怪堆存成紀錄（`~/.tabbybot/cluster_sites.json`），重開也不會忘；之後照紀錄自動挑要去哪一堆打。
- 全圖探索：地圖沒探索過時會繞完整張圖記下怪堆，探索完就不再定期探索。
- 選堆：優先去沒人打的怪堆；一堆有 1–2 個其他玩家可以一起打，3 人以上才換堆。走去怪堆的路上不打路邊單隻（精英例外）。
- 風箏：以怪堆中心為圓心繞著拉，不會越拉越遠；怪貼身時先拉開距離。
- 精英：一律優先打、一律風箏；拉不開時先後撤脫仇恨，等它回頭再追打，重複到打死。
- 禁止喝水開關：控制台可勾「禁止喝水」，程式完全不喝生命藥水（預設開）。
- 任務刷新開關（測試中）：沒有可接的任務時，重新抓任務清單看會不會換；不取消、不跳過、不耗任務次數（預設關）。
